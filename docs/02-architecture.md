# 02. 아키텍처

**확정 · 2026-11-26**

코어는 뷰포트 설정과 장면 입력을 소유합니다. GPU 출력의 디바이스·명령 인코더·색 타깃은 호스트 수명에 묶고, 디바이스별 파이프라인·버텍스/인덱스 버퍼·깊이 타깃은 렌더러가 관리합니다. 디바이스 교체 때 GPU 리소스를 다시 만들 수 있도록 앱이 원본 메시를 보유합니다.

GPU 구현은 Serge와 동일한 `wgpu` 계열과 정확한 버전을 사용합니다. 패밀리에서 해당 크레이트를 포크할 때 소유자는 Serge입니다. 현재 Serge는 `wgpu =30.0.2`를 고정했고, Opale의 설정 크레이트는 Rust 1.85에서 GPU 의존성 없이 빌드됩니다. 공동 디바이스를 쓰는 어댑터의 빌드 기준은 두 GPU 소비자가 요구하는 더 높은 최소 Rust 버전입니다. UI나 백엔드 크레이트를 코어 의존성으로 추가할 필요가 없습니다. [Serge의 의존 선언](https://github.com/hyperish/serge/blob/main/Cargo.toml) · [Opale 워크스페이스](../Cargo.toml)

뷰포트 v1의 소프트웨어 경로는 같은 기본 메시·카메라를 CPU로 래스터화해 동일한 물리 픽셀 규약으로 제공합니다. 호스트가 GPU를 잃어도 앱의 장면 데이터는 유지됩니다. HDR, 광역 색, OS·프로세스 간 GPU 메모리 가져오기는 v1 지원 범위 밖입니다.
