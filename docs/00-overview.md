# 00. 제품 범위

**확정 · 2026-11-26**

`opale`은 앱과 에디터에 내장하는 실시간 3D 뷰포트 렌더러입니다. 첫 사용자는 같은 창에서 3D 장면을 조작하면서 일반 UI로 선택과 설정을 편집하는 앱 개발자입니다. 첫 납품 단위는 카메라 하나로 변환된 인덱스 메시와 단색 재질을 깊이 검사해 그리고, 호스트가 그 위에 UI를 합성하는 뷰포트입니다.

| 주체 | 소유하는 것 |
|---|---|
| 앱 | 장면 데이터, 편집·저장, 카메라 조작 정책 |
| `opale` | 카메라·메시·변환의 렌더 입력, 렌더 파이프라인, 깊이 버퍼, 한 뷰포트의 출력 |
| 호스트(`serge` 등) | 창이나 DOM, 레이아웃·입력·접근성, 프레임 예약, 최종 표시 |

첫 버전은 프레임을 명시적으로 요청하는 Rust 라이브러리로 배포합니다. 월드/ECS, 물리, 게임 루프, 범용 에디터, 위젯과 백엔드 서비스는 앱이나 다른 레포의 책임입니다. `opale`의 일정은 패밀리의 Phase 1~3 출시 조건과 독립적입니다.

출발점은 기존 크레이트의 물리 픽셀 크기·선형 색·백엔드 서술자와 Serge의 외부 뷰포트 요구입니다. Bevy의 공식 예제는 카메라가 텍스처에 그린 결과를 두 번째 패스에서 소비하는 사례입니다. 제품 범위와 첫 장면은 이 레포의 결정입니다. [현재 공개 API](../crates/opale/src/lib.rs) · [Render to Texture](https://bevy.org/examples/3d-rendering/render-to-texture/)
