# 05. 구현 계획

**확정 · 2026-11-26**

현재 구현된 것은 `ViewportDesc`, `Extent2D`, `GraphicsBackend`, `Color`와 설정 단위 테스트입니다. 아래 단계는 렌더러를 출시할 때 충족할 조건입니다.

| 단계 | 완료 기준 |
|---|---|
| 장면·소프트웨어 기준 이미지 | 작은 인덱스 메시 두 개가 겹치는 고정 장면에서 카메라 변환, 깊이, 배경색을 픽셀로 검사합니다. 크기가 0이었다가 복구되는 경우를 포함합니다. |
| 네이티브 GPU | 같은 장면을 같은 디바이스에서 호스트 UI의 앞뒤로 합성합니다. 소프트웨어 경로와 클립·색·알파를 Serge의 허용 오차로 비교하고, resize·해제 후 과거 세대가 표시되지 않는지 검사합니다. |
| 웹 | 실제 브라우저에서 두 캔버스를 서로 다른 크기로 렌더합니다. 배율 변경과 포인터 입력, DOM 오버레이의 가림·클릭, 언마운트, WebGPU를 사용할 수 없을 때 CPU 출력을 확인합니다. |

렌더러의 인수는 Opale과 호스트를 실제로 연결한 테스트가 기준입니다. 기반 GPU API의 실험 결과는 [Serge의 통합 계획](https://github.com/hyperish/serge/blob/main/docs/05-implementation-plan.md#integration-checks)에 기록합니다.
