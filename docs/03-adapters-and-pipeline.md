# 03. 호스트 어댑터

**확정 · 2026-11-26**

네이티브에서는 호스트가 할당한 색 타깃과 명령 인코더를 한 프레임 동안 빌립니다. Opale이 생산 패스를 닫으면 Serge가 같은 디바이스에서 텍스처를 샘플링해 UI를 합성하고 큐에 제출합니다. 소프트웨어 출력도 같은 슬롯에 배치합니다. 슬롯 세대, 픽셀 형식·알파, 크기 변경, 디바이스 상실은 소비자와 함께 지켜야 하므로 Serge가 계약 원문을 소유합니다. [Serge 뷰포트 v1](https://github.com/hyperish/serge/blob/main/docs/03-adapters-and-pipeline.md#viewport-v1)

웹에서는 호스트의 전용 캔버스 안에 그립니다. DOM 오버레이의 이벤트는 호스트가 먼저 처리하고, 뷰포트로 들어온 포인터 좌표는 호스트가 슬롯 기준 물리 픽셀로 바꿔 앱에 전달합니다. 같은 페이지에서 캔버스 둘을 마운트하더라도 크기·입력·해제는 각 슬롯에만 적용됩니다. [WebGPU 캔버스](https://www.w3.org/TR/webgpu/#canvas-rendering)
