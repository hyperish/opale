# 01. 사용 API

**확정 · 2026-11-26**

현재 `ViewportDesc::new(width, height)`는 물리 픽셀 크기, 기본 `GraphicsBackend::WebGpu`, 불투명 검정을 보관합니다. `with_backend`와 `with_clear_color`로 설정을 바꿀 수 있습니다. 백엔드 열거형은 요청할 수 있는 종류를 표현합니다. 실행 가능한 백엔드는 렌더러를 연결할 때 확인합니다. [API 및 단위 테스트](../crates/opale/src/lib.rs)

첫 렌더러의 사용 순서는 다음과 같습니다.

1. 호스트가 뷰포트에 맞는 타깃을 만들고, 앱이 카메라와 인덱스 메시·변환·색을 제공합니다. 메시를 올린 뒤에는 같은 뷰포트의 여러 프레임에서 재사용합니다.
2. 입력이나 장면이 바뀌면 호스트가 프레임을 예약합니다. 렌더러는 그 프레임의 타깃에 명령을 기록하고 제어를 호스트에 돌려줍니다. 정지 장면을 위해 별도 이벤트 루프를 돌리지 않습니다.
3. 호스트는 크기와 배율을 갱신하고 마운트가 끝나면 뷰포트를 해제합니다. 한 축이 0이면 그리기를 쉽니다. 크기가 복구되면 마지막 장면을 새 타깃에 그립니다.

장면과 카메라 조립에는 일반 Rust 값과 메서드를 씁니다. 이 호출 순서는 렌더러 구현의 계약입니다.
